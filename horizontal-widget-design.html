Key Design Principles

🎯 Action-First Design
  • • Save button is always the largest, most prominent element
  • • One-click access to all primary actions
  • • Visual hierarchy guides users to most important features
  • • Minimal clicks to accomplish any task
📏 Adaptive Width
  • • Starts compact (600px) for minimal screen usage
  • • Expands horizontally as widgets are added
  • • Widgets can collapse to icons to save space
  • • Scrollable on smaller screens
🖱️ Top-Screen Optimized
  • • Designed to sit at top of screen
  • • Works perfectly with Claude at bottom
  • • Always accessible without alt-tabbing
  • • Can auto-hide when not in use
