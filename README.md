# GitSave

A dead-simple menu bar app for non-developers to save their work with Git.

## Features

- **One-click save**: Commits and pushes changes with a single button
- **Menu bar integration**: Shows current project and branch
- **Simple UI**: Big save button, optional commit message
- **Basic Git operations**: Save, Sync, Push

## Usage

1. Click the GitSave icon in your menu bar
2. Select "Change Project" to choose a Git repository
3. Click "Save Changes" to commit and push
4. Use Cmd+S as a keyboard shortcut to save

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run dist
```
